# 블로그 포스트 작성 스킬

이 스킬은 에이전트가 외부 콘텐츠(LinkedIn 포스트, 기사)를 SEO 최적화된 GitHub.io 블로그 포스트 형식으로 변환하는 데 도움을 줍니다.

## 빠른 시작

1. 소스 콘텐츠 수집 및 기존 블로그 포스트 형식 분석
2. 적절한 메타데이터로 Frontmatter 생성
3. 기존 패턴을 따라 콘텐츠 구조화
4. 이미지 관리 및 경로 최적화
5. 프로젝트 정보로 콘텐츠 보강
6. 태그 추가 및 SEO 최적화
7. 검증 및 로컬 테스트

## 주요 기능

- 외부 소스에서 형식 변환
- SEO 최적화 (excerpt, alt 텍스트, 내부 링크)
- 이미지 관리 및 경로 매핑
- 프로젝트 데이터로 콘텐츠 보강
- 기존 포스트와 일관된 구조
